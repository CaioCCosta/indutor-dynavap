# Pack v1 — cavas + inserts (cola)

**v1 fechada (set/2026).** Variante de cola. A outra variante oficial é [`../v1/`](../v1/) (relevo AMS).

Aqui o tribal é **cava** na casca; os inserts saem deitados para colar.

| Arquivo | O quê |
|---|---|
| `corpo_cava.stl` | Corpo com cavas 0,6 mm + pads |
| `tampa_cava.stl` | Tampa com cava 0,6 mm |
| `decais.stl` | Os 6 inserts numa placa |
| `decal_frente.stl` … `decal_tampa.stl` | Inserts soltos (0,5 mm, folga XY) |

## Impressão

1. Corpo e tampa: PETG, piso no bed / tampa deitada, **sem** Assemble com os decais.
2. `decais.stl`: deitado, 0,5 mm = ~2–3 camadas 0,2 mm. Cor de contraste.
3. Cola cianoacrilato ou epóxi nas cavas. Lixar se o insert ficar alto.

Não misture com `print/v1` no mesmo Assemble.
